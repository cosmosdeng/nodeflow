# NodeFlow — 跨平台节点式流程绘图工具

一个基于 **Electron + React + React Flow** 的通用节点式流程图工具,可在 **macOS(Apple Silicon / Intel)/ Windows / Linux** 上运行。

> 两条发布线:
>
> - **正式版(Stable):v0.3.2**(main 分支)— 参与方 / 组织管理、阶段域注释、`.nodeflow` v4 兼容层等,推荐稳定使用。macOS 提供 **Apple Silicon(arm64)** 与 **Intel(x64)** 两种安装包。
> - **Next 预览版:v0.4.0-next.2**(next 分支)— 在正式版之上新增「参与方×阶段」矩阵、语义再指派等功能,详见下文[正式版与 Next 预览版差异](#stable-vs-next)。next 分支当前还包含已通过完整验证的 Agent Interface + MCP Adapter(尚未随版本发布)。
>
> 两者都是**免费开源的桌面应用**,安装方式完全相同,只是功能线不同。

## 功能特性

- **节点**:每个节点可配置多个输入 / 输出端口,包含名称与简短动作描述
- **执行主体标识**:节点 / 组合节点按执行主体用不同颜色外框标识 —— **人工(黄)、机器(蓝)、人机协同(紫文字 + 绿框)**,带同色光晕,提高可读性
- **组合节点**:多节点编组为复合节点,支持展开 / 塌缩无损切换、内部画布(标签页 / 弹窗)、解除编组;样式自动继承内部节点的执行主体颜色,支持**嵌套组合**
- **流程阶段域**:矩形虚线框区域(工具栏「▦ 添加阶段域」),把相关节点划入同一阶段;节点拖入后**长按 1 秒**归属(域自动扩大包裹节点并推挤外部元素),域内节点 / 连线 / 产物完全不受影响
- **参与方 / 组织管理**:在「👤 参与方」面板管理参与方与组织(个人 / 角色 / 组织 / 部门 / 机器 / 软件 / AI 智能体),节点 / 组合节点可在属性面板分配所属参与方(显式 Assign,只改语义不改位置),并随 `.nodeflow` 文件持久化
- **「参与方×阶段」矩阵**(Next 预览版独有):参与方**行带**与阶段**列带**可视化(可分别开关显示),节点归属后自动纳入对应行列带;带保持顺序且**弹性移动**去包含节点;空参与方保持最小高度带
- **语义再指派**(Next 预览版独有):把节点拖到带 / 交叉格停留约 1 秒,出现候选高亮与确认框,可只改参与方或只改阶段;自动排列会按「参与方×阶段」矩阵语义排布并沿连线整理
- **Agent / MCP 接口**(next 分支开发中,尚未发布):本地 Agent Bridge(仅本机 HTTP)+ MCP(stdio)适配层,支持 Observe / Command / Assert / Screenshot / Capabilities,与 GUI 共用同一套 domain / history / revision
- **BPMN 网关**:逻辑判断 / 分支节点 —— **排他(×)/ 并行(+)/ 包容(○)** 三种菱形网关,可分支(一进多出) / 汇聚(多进一出);分支条件通过连线说明表达;画布右键直接创建,网关上右键切换类型;各分支连线彩色区分
- **注释框**:画布 / 节点 / 连线 / 中间产物 / 组合 / 网关 / 阶段域均可添加注释框(收起时显示红色 pin 📌,展开可编辑标题与内容,支持多段内容);删除主体自动清理其注释
- **自动排列**:工具栏「自动排列」一键整理全画布或组合内部节点 —— 正式版按横向拓扑分层布局(全画布时自动集成阶段域:域内节点横向排列、域框收敛、各域作为整体块排列);Next 预览版在显示 Stage/Participant 带时改为按「参与方×阶段」矩阵语义排布并沿连线整理,两个带都隐藏时退化为纯自动排列
- **连线**:连线上可添加说明文字,以及中间产物(文档 / 图像 / 视频 / 音频 / 代码 / 数据 / 其他)
- **连线快速建节点**:从端口拖线到画布空白处自动创建新节点并连接
- **无限画布**:平移、缩放、框选多节点,双击画布空白处快速创建节点
- **复制 / 粘贴**:选中节点或组合后 `Ctrl/⌘+C`、`Ctrl/⌘+V` 复制粘贴,支持**跨画布标签、跨项目**复制粘贴;组合节点递归复制整个子图(自动重新生成 id 与端口映射)
- **多项目 / 多画布**:标签栏管理多个项目文档 + 项目内主画布 / 组合内部画布标签,每个项目独立保存、独立历史
- **保存 / 打开项目**:`.nodeflow` 项目文件保存完整编辑状态(含撤销 / 重做历史),双击文件自动打开恢复;也支持导入 / 导出静态 JSON
- **导出**:导出 JSON / JPG / PDF,可选 A5 / A4 / A3 / Letter 幅面(默认横版、完整画布居中适配)
- **自动保存**:所有修改防抖后自动保存到本地,刷新 / 重启不丢失
- **历史回溯**:完整撤销 / 重做 / 跳转到任意历史快照
- **大纲面板(左)**:展示全部节点,支持搜索、按执行主体分组,点击定位到画布
- **属性面板(右)**:选中节点 / 连线 / 中间产物后即可编辑其全部属性
- **右键上下文菜单**:画布 / 节点 / 复合节点右键弹出快捷操作菜单
- **删除确认**:删除节点 / 连线弹确认对话框;端口可悬停删除(每方向至少保留 1 个),删除端口会同步删除关联连线;所有删除均可用撤销完整还原
- **单元测试**:核心纯函数(组合端口 / 执行主体 / 布局算法 / 复制粘贴 / 阶段域 / 网关 / 参与方)与组合状态机 / Agent 断言 / MCP 均有 vitest 覆盖(当前开发线 312 用例 / 34 文件全量通过)

## 正式版与 Next 预览版差异

| | 正式版 Stable | Next 预览版 |
| --- | --- | --- |
| 分支 | `main` | `next` |
| 最新版本 | **v0.3.2** | **v0.4.0-next.2**(其后还有 Agent/MCP 开发中) |
| 安装 | GitHub Releases(正式 Release) | GitHub Releases(标为 Pre-release) |
| 适合人群 | 追求稳定、用于真实绘图 | 想尝鲜矩阵 / 参与方可视化 / Agent 能力的用户 |
| 参与方 | 可在「参与方」面板管理参与方 / 组织;节点属性面板可分配参与方(显式 Assign,语义不改几何) | 全部继承正式版,并新增参与方**行带**可视化、弹性带包含节点 |
| 阶段 | 流程阶段域(矩形虚线框、长按归属、自动扩大推挤),阶段域可加注释 | 全部继承,并新增阶段**列带**可视化、属性面板「所属阶段」下拉、两轴带可独立开关 |
| 交互 | 拖动节点到阶段域内长按归属 | 新增**语义再指派**:拖节点到带 / 交叉格悬停约 1 秒 → 候选高亮 → 确认,可单独改参与方或阶段 |
| 自动排列 | 拓扑分层布局 + 阶段域整体块排列 | 有 Stage/Participant 带时按「参与方×阶段」矩阵语义排布并沿连线整理;无带 / 带隐藏时退化为自动排列 |
| 持久化 | `.nodeflow` v4(含 v2/v3 旧档自动迁移、版本门校验) | `.nodeflow` v5(新增参与方 / 阶段排序状态) |
| Agent / MCP | 不包含 | next 分支已实现:本地 Agent Bridge(仅本机 HTTP)+ MCP(stdio)适配层,支持 Observe / Command / Assert / Screenshot / Capabilities,与 GUI 共用 domain / history / revision;见下方 [MCP / AI Agent Integration](#mcp--ai-agent-integration) |

两条线共享同一套核心数据模型与项目文件格式:正式版保存 `.nodeflow` v4,Next 保存 v5。v4 及更早的项目在 Next 中打开会自动迁移到 v5;**反过来不行** —— 版本门会拒绝在旧版打开由更高版本保存的文件,用 Next 编辑过的项目回到正式版打开前需在 Next 里另存为 v4 兼容(或直接继续用 Next)。

> 想用正式版,直接在 [Releases](https://github.com/cosmosdeng/nodeflow/releases) 下载 v0.3.2 安装包即可;想体验 Next 预览,选择 Pre-release 中的 `v0.4.0-next.x`。

## 快速开始

```bash
# 安装依赖
bun install        # 或 npm install

# 浏览器开发模式
bun run dev        # 打开 http://localhost:5173

# 桌面应用(先构建再启动 Electron)
bun run build
bun run start

# 打包为安装程序(自动注册 .nodeflow 文件关联)
bun run dist:mac   # macOS (dmg/zip);可加 --arm64 / --x64 指定架构
bun run dist:win   # Windows (nsis/zip)
bun run dist:linux # Linux (AppImage/deb)

# 运行单元测试
bun run test
```

> 若 electron 二进制下载失败,可设置镜像后重装:
> `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ bun install`

## 使用说明

### 画布基本交互

| 操作 | 方式 |
| --- | --- |
| 移动节点 | 左键按住节点拖动 |
| 框选多个节点 | 左键在画布空白处拖拽画框 |
| 平移画布 | 右键按住拖动;mac 触控板两指滑动;Windows 右键拖动 |
| 缩放画布 | 鼠标滚轮(以光标为中心),触控板两指捏合,或右下角缩放控件 |
| 创建节点 | 双击画布空白处,工具栏「＋ 添加节点」,或画布右键菜单「添加节点」 |
| 编辑文字 | 左键**双击**节点标题 / 描述 / 端口名;新建节点 / 端口 / 连线说明时自动进入编辑态 |
| 连线 | 从节点输出端口拖到另一节点输入端口 |
| 连线快速建节点 | 从端口拖线到画布空白处,自动创建新节点并连接 |
| 复制 / 粘贴 | 选中节点后 `Ctrl/⌘+C` 复制、`Ctrl/⌘+V` 粘贴(可跨画布 / 跨项目);或右键菜单 |
| 自动排列 | 工具栏「自动排列」(横向拓扑布局;选中组合时只排组合内部) |
| 删除 | 选中节点 / 连线后按 Delete / Backspace,或右键菜单「删除」(弹确认对话框;撤销 Ctrl/⌘+Z 可还原) |

### 文件菜单

- **新建项目**:新建一个空项目文档(多项目可并排标签管理)
- **打开项目**:从 `.nodeflow` 项目文件恢复完整编辑状态与历史
- **保存项目**:把当前项目(含撤销 / 重做历史)保存为 `.nodeflow` 文件
- **关闭项目**:关闭当前项目(有未保存修改时提示保存)
- **导入 → 导入 JSON**:加载静态画布 JSON
- **导出 → 导出 JSON / JPG / PDF**:导出静态画布或图片,可选 A5 / A4 / A3 / Letter 幅面(默认横版、完整画布居中)
- **清空画布**

### 右键菜单

- **画布空白处右键**:添加节点 / 添加网关(排他 / 并行 / 包容)/ 锁定全部 / 连线风格切换 / 显示全部节点 / 保存 / 另存为(导出 JSON)
- **节点上右键**:复制(支持组合递归复制)/ 粘贴 / 锁定 / 编组为复合节点 / 删除
- **网关上右键**:切换网关类型(排他 / 并行 / 包容) / 删除
- **复合节点上右键**:额外提供「展开(显示内部节点)/ 收起(塌缩组合)」「解除编组」
- **连线上右键**:「在此添加节点」(在连线中间插入新节点,原连线拆成两段,说明 / 产物 / 注释移到上游连线)/「删除连线」

### 组合节点

| 操作 | 方式 |
| --- | --- |
| 编组 | 选中 ≥2 个节点,右键菜单「编组为复合节点」 |
| 嵌套组合 | 已存在的组合节点可再编入新组合(递归透出聚合端口) |
| 展开 / 塌缩 | 点击组合节点上的 ▶(展开)/ ◀(塌缩)按钮,或直接双击组合节点 |
| 内部画布 | 标签页打开,或「在新窗口弹出内部画布」 |
| 解除编组 | 复合节点右键菜单「解除编组」 |
| 删除 | 需先展开,再删除(会还原内部节点与连线) |

### 流程阶段域

| 操作 | 方式 |
| --- | --- |
| 添加 | 工具栏「▦ 添加阶段域」(画布中央创建) |
| 节点进入域 | 把节点拖入域框内,继续**按住 1 秒**(节点 + 域闪烁),节点归属该域;未长按仅视觉叠加 |
| 自动扩大 | 拖拽域内节点时域框自动扩大包裹节点,并把重叠的外部节点 / 组合 / 其他域推开 |
| 拖拽移动 | 按住域**四边拖拽条**或**头部**拖动(内部节点保持相对关系整体移动) |
| 调整大小 | 拖**右下角手柄**;缩小最小只能覆盖所有域内节点 |
| 编辑名称 | 新建域自动进入名称编辑;双击域名称进入编辑 |
| 脱离阶段域 | 选中一个或多个节点 → 右键「脱离阶段域」;域右键「脱离全部节点」 |
| 删除阶段域 | 域上右键「删除阶段域」或选中后按 Delete 键;内部节点 / 组合自动脱离、连线不变 |

### BPMN 网关

| 操作 | 方式 |
| --- | --- |
| 创建 | 画布空白处右键 →「排他网关(×)/ 并行网关(+)/ 包容网关(○)」 |
| 切换类型 | 网关上右键「切换为...网关」 |
| 分支 | 点菱形右侧直角内 `+` 添加输出分支;分支条件写在连线说明里 |
| 汇聚 | 点菱形左侧直角内 `+` 添加输入端口;多个上游连入 |
| 删除分支/输入 | 悬停端点,点删除 `×`(每侧至少保留 1 个) |
| 执行主体图标 | 菱形上方图标,点击轮换人 / 机器 / 人机协同 |
| 锁定 | 菱形下方图标 🔓/🔒,点击锁定/解锁 |
| 分支连线颜色 | 各分支引出的连线颜色不同(按分支序号取色),便于区分走向 |
| 注释 | 悬停时红 pin 显示于锁定键下方;有注释持续显示 |
| 编组 / 阶段域 / 复制粘贴 | 网关与普通节点完全同等处理:可编组进组合、长按加入阶段域、复制粘贴(保留网关类型)、锁定、注释等 |

### 注释框

| 操作 | 方式 |
| --- | --- |
| 添加注释 | 悬停节点 / 连线 / 产物 / 组合 / 网关,点击其 **红色 pin 📌**;或画布空白处右键「添加注释」 |
| 展开 / 收起 | 点击红 pin 展开注释框,再次点击收起 |
| 编辑 | 注释框展开后编辑标题与内容(多段) |
| 自动清理 | 删除节点 / 连线 / 产物 / 组合时,其注释自动删除 |

### 其它

| 操作 | 方式 |
| --- | --- |
| 编辑属性 | 选中节点 / 连线 / 中间产物,在右侧「属性」面板修改 |
| 添加 / 删除端口 | 节点上「＋」添加;悬停端口出现删除图标,点击删除(每方向至少保留 1 个) |
| 添加中间产物 | 选中连线后点击连线上的「+」,或在属性面板中添加 |
| 撤销 / 重做 | 工具栏按钮,或 Ctrl/⌘+Z、Ctrl/⌘+Shift+Z |
| 回溯历史 | 打开「历史」面板,点击任意历史快照 |
| 保存 | 自动保存,也可 Ctrl/⌘+S 手动保存 |

> 画布左上角有可缩小的操作提示框,随时查看基本交互。

## 技术栈

- [Electron](https://www.electronjs.org/) — 跨平台桌面壳(含 `.nodeflow` 文件关联)
- [React](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/) + [Vite](https://vitejs.dev/)
- [React Flow](https://reactflow.dev/) — 无限画布、节点连线交互
- [Zustand](https://zustand-demo.pmnd.rs/) — 状态管理、自动保存、历史快照
- [vitest](https://vitest.dev/) — 单元测试
- [html-to-image](https://github.com/bubkoo/html-to-image) + [jsPDF](https://github.com/parallax/jsPDF) — 图片 / PDF 导出
- [Model Context Protocol SDK](https://modelcontextprotocol.io/) + [zod](https://zod.dev/) — Agent / MCP 线(next 分支)

## 项目结构

```
nodeflow/
├── electron/            # Electron 主进程(文件关联 / 双击打开 / Agent Bridge)与 preload
├── src/
│   ├── components/      # 画布、节点、连线、大纲、属性、历史、工具栏等组件
│   ├── agent/           # Agent Interface(executor / queries / commands / assertions / capabilities)
│   ├── mcp/             # MCP Adapter(schemas / server / stdio / bridge)(next 分支)
│   ├── store/           # Zustand 状态(多项目 / 历史 / 自动保存 / 剪贴板)
│   ├── lib/             # 核心纯函数(组合端口 / 执行主体 / 布局 / 导出 / 复制粘贴 / 弹性带)
│   ├── styles/          # 全局样式与画布主题
│   ├── types.ts         # 数据模型定义
│   ├── App.tsx          # 主界面布局
│   └── main.tsx         # 入口
└── package.json         # 依赖、脚本与 electron-builder 打包配置
```
