# UI/UX 设计规范 — NodeFlow

> 本文档汇总 NodeFlow 到目前为止的 UI/UX 设计、历次修改与调整决策,作为视觉与交互的统一基线。代码实现位于 `src/styles/global.css` 及各组件,本文档与代码保持一致,修改样式 / 交互时需同步更新。

## 1. 设计语言总览

NodeFlow 是一款**节点式流程绘图工具**,设计目标是:深色优先、高可读、语义化配色、交互即时反馈。核心原则:

1. **深色优先**:默认深色主题,提供浅色主题一键切换;所有颜色经 CSS 变量定义,主题切换即变量切换。
2. **语义化配色**:执行主体(人工 / 机器 / 人机协同)用固定颜色标识;连接状态、锁定、危险操作均用约定色表达。
3. **选中不掩盖语义**:选中态**不改变**节点 / 连线的语义色(执行主体色),而是提亮 + 增强光晕,避免"蓝色=机器"与"选中=蓝"混淆。
4. **即时反馈**:悬停放大 / 提亮、编辑态高亮描边、危险操作红色,所有可交互元素有清晰的 hover 态。
5. **极简表面**:面板扁平化(无重投影),节点用轻投影区分离画布与元素层级。

## 2. 主题与色彩系统

### 2.1 双主题

| 主题 | 触发 | 默认 | 说明 |
| --- | --- | --- | --- |
| 深色 `dark` | `document.documentElement.dataset.theme = 'dark'` | ✅ | 默认主题 |
| 浅色 `light` | `[data-theme='light']` 变量覆盖 | — | 工具栏 🌙/☀️ 一键切换,持久化 |

### 2.3 执行主体色(Actor)语义色

| 执行主体 | 图标 / 文字色 `color` | 外框 / 光晕色 `frame` | 标签底 `bg` |
| --- | --- | --- | --- |
| 人工 `human` | 黄 `#e8b028` | 黄 `#e8b028` | `rgba(232,176,40,.14)` |
| 机器 `machine` | 蓝 `#4ea1ff` | 蓝 `#4ea1ff` | `rgba(78,161,255,.14)` |
| 人机协同 `hybrid` | 紫 `#9d6bff` | **绿** `#22c55e` | `rgba(157,107,255,.14)` |

> **设计决策**:人机协同节点文字用紫色 `#9d6bff` 以区分机器蓝,但外框用绿色 `#22c55e` 区分三者(黄 / 蓝 / 绿三色外框最易读)。机器蓝取纯正蓝 `#4ea1ff`(与主题 accent 一致),避免偏青。

## 4. 组件规范

### 4.1 节点(Node)

| 属性 | 值 | 说明 |
| --- | --- | --- |
| 尺寸 | 宽 `230px`(不随标题变化) | 长标题**换行成多行**,不截断不省略 |
| 圆角 | `12px` | — |
| 底 | `--bg-panel` | — |
| 描边 | `1px --border-strong` | 悬停变 `--border-hover` |
| 投影 | `--shadow` | 轻投影区分离层级 |

**头部**:主体图标 + 可编辑标题 + 右上角操作按钮(主体轮换 🔄 + 锁定 🔒)。
**标题**:`700 / 13px`,`white-space: normal`,允许换行。
**描述**:次级文字,空态显示"暂无描述"。
**选中态**:边框提亮 `currentColor 78%` + 外圈高亮 `currentColor 45%` + 光晕 `currentColor 50%`,**不改变语义色**。

### 4.2 端口(Port)

- 输入端口在**左**(`type="target"`),输出端口在**右**(`type="source"`)。
- Handle:圆形 `10px`,accent 色 + `--handle-border` 描边。
- **命中区域放大**:`::after` 扩展 `-10px` inset,视觉不变但易点。
- **连接状态光晕**:已连接绿 `#22c55e` / 未连接桔 `#fb923c`,带 3px 外圈 + 14px 光晕;悬停进一步放大光晕。
- 端口删除:该方向 ≥2 时**悬停显示删除按钮**(红色),删除同步清理关联连线。
- 端口添加:`+` 按钮(输入左下 / 输出右下),虚线圆,悬停 accent 填充 + 光晕。
- 端口标签:内联可编辑。

### 4.3 连线(Edge)

- **描边**:`--edge-stroke` 默认色。
- **层级**:默认节点在上、连线在下(节点清晰);拖拽节点时临时把连线 / label 提升到节点之上(便于看清连线关系)。
- **选中态**:`.react-flow__edge-path` 用 accent 色 + `stroke-width: 4` 加粗。
- **说明 label**:胶囊 `border-radius: 999px`,`--chip-bg` 背景,悬停 accent 描边;编辑态展开 `max-width: 320px` 允许换行。
- **绕障路径**:连线(含 label / 产物)默认不与节点重叠,由 `edgePath.ts` 计算绕行。

### 4.4 组合节点(Composite)

| 形态 | 样式 |
| --- | --- |
| 塌缩 `.nf-composite-node` | 普通节点 + **4px 粗边框**(accent 55% + strong 混合),标题旁 `⧉` 图标 |
| 展开 `.nf-composite-frame` | **3px 虚线框**包裹子节点,框体 `pointer-events: none`(内部节点可交互),标题栏单独 `auto` |
| 选中 | 提亮边框 + 增强外圈 / 向内光晕,保留执行主体色 |

- **执行主体自动继承**:内部全同则同色,混杂则人机协同(绿框);图标 / 边框实时跟随。
- 展开 / 塌缩有**淡入 + 轻微缩放动画**(`nf-composite-pop`)。
- 展开态内部节点通过 `className: nf-expanded-frame` + `zIndex:1` 保证可拖 / 连线 / 选中。

### 4.5 流程阶段域(Stage)

| 属性 | 值 | 说明 |
| --- | --- | --- |
| 形态 | 矩形虚线框(2px dashed) | 内部填充与边框同色,低饱和低明度光谱色(按域水平位置红→蓝紫) |
| 填充 | `color-mix(光谱色 12%)` | 低调不花,`--stage-color` 变量控制 |
| 名称 | 顶部胶囊,双击可编辑 | 含节点计数徽标 |
| 穿透 | 整体 `pointer-events: none` | 域内节点 / 连线 / 产物完全正常操作 |
| 拖拽移动 | 四边拖拽条(9px)+ 头部 | 内部节点保持相对关系整体移动 |
| 调整大小 | 右下角手柄 | 缩小最小只能覆盖所有域内节点(内边距 22),再小无效 |
| 自动扩大 | 拖拽域内节点时按包围盒扩大 | 扩大后推挤重叠的外部节点 / 组合 / 其他域(间距 14) |
| 选中态 | 实线边框 + 柔和光晕 | — |

- **归属(长按进入)**:节点拖入域框后**继续按住 1 秒**才归属(节点 + 域闪烁反馈);否则仅视觉叠加;一节点只能属一个域。
- **脱离**:选中一个或多个节点右键「脱离阶段域」;域右键「脱离全部节点」「删除阶段域」。

### 4.6 锁定状态

- **节点锁定**:虚线边框 `border-style: dashed`,头部 / 描述 / 端口 label 透明度降至 `.78`;锁定按钮变金色 `#e8b028` + 光晕。
- **全局锁定(演示模式)**:禁止一切结构变更,所有操作按钮 `disabled`(灰度 + 降透明度)。

### 4.7 内联编辑(EditableText)

- 编辑态:`outline: 2px solid var(--accent)` + `accent 8%` 淡背景;空态显示斜体占位符。
- 提交:失焦 / 回车;取消:`Esc`。
- 标题换行、描述多行、端口标签扩展——编辑态均解除宽度 / 高度限制。
- **新建对象默认进入编辑态**:新节点标题 / 新连线说明 / 新端口 label 创建后自动聚焦。

### 4.8 中间产物与注释

- 中间产物 chip:`--chip-bg-strong` 背景,图标 + 文字标签,悬停显示删除。
- 注释框:半透明、点状虚线边框、无背景;红色 pin 📌 标识(悬停 / 收起时显示)。

### 4.9 面板

- 统一 `--bg-panel` 背景、`--border` 分隔线;列表项选中态 `--accent-soft` 底 + accent 45% 描边。
- 画布左上角有**可缩小操作提示框**;左下全局缩略图(MiniMap)、右下缩放控件。

## 5. 交互规范

| 交互 | 行为 |
| --- | --- |
| 拖拽节点 | 左键按住节点移动 |
| 框选 | 左键画布空白拖拽 |
| 平移画布 | 右键拖拽;mac 两指滑动 |
| 缩放 | 滚轮(以光标为中心) / 触控板捏合 / 右下控件 |
| 创建节点 | 双击画布空白 / 工具栏「＋」/ 右键「添加节点」 |
| 编辑文字 | 左键**双击**标题 / 描述 / 端口名;新对象创建后**自动进入编辑态** |
| 连线 | 从输出端口拖到另一输入端口 |
| 连线快速建节点 | 端口拖到空白自动建节点并连接 |
| 复制 / 粘贴 | `Ctrl/⌘+C`、`Ctrl/⌘+V`,可跨画布 / 跨项目 |
| 自动排列 | 工具栏「自动排列」+ 横向 / 竖向(选中组合只排内部) |
| 删除 | Delete / Backspace 或右键菜单,弹**确认对话框**;撤销可还原 |
| 右键菜单 | 画布 / 节点 / 复合节点 / **连线**四类快捷菜单 |
| 关闭项目 | 标签栏 × 或文件菜单,有未保存修改时**提示保存** |

## 6. 历次设计调整决策记录

按时间倒序,汇总对 UI/UX 的关键修改与调整:

1. **自动排列集成阶段域 + 去竖向**:全画布自动排列时各阶段域作为整体块参与横向拓扑排列(域内节点先横向排列、域框收敛包裹;单节点域框大小对齐「除自身外最大的域」;所有域垂直中心水平对齐);移除竖向排列,自动排列固定横向。
2. **阶段域交互细节**:新建域自动进入名称编辑;双击名称编辑(不误建节点);新建域自动放画布空白处;点击空白取消域选中;Delete 键可删除选中域(内部节点 / 组合自动脱离、连线不变);四边拖拽条 9px→14px 扩大命中。
3. **流程阶段域(Stage)**:矩形虚线框,低饱和光谱色(按水平位置红→蓝紫,内部填充与边框同色);节点拖入后**长按 1 秒进入**(节点+域闪烁),未长按仅视觉叠加;域整体穿透,内部节点 / 连线 / 产物完全正常操作;拖域通过四边拖拽条 + 头部,右下角手柄调整大小,缩小最小覆盖所有域内节点;拖拽域内节点时域框自动扩大并把重叠的外部元素按最小位移推开(保持间距)。
2. **连线右键菜单 + 组合节点右键展开/收起**:连线右键新增「在此添加节点」(在连线中间插入新节点,原连线拆成两段,说明 / 产物 / 注释全部移到上游连线,新节点自动进入标题编辑)与「删除连线」;组合节点右键新增「展开(显示内部节点)/ 收起(塌缩组合)」。
2. **展开组合节点内部可交互**:组合框 `pointer-events: none` 穿透,内部节点可拖 / 连线 / 选中;弃用不兼容的 `:has()`,改用 `className` 精确类选择器 + 内部节点 `zIndex` 提升。
3. **节点标题长文本换行**:不再单行省略号截断,允许换行成多行,节点宽度不变。
4. **新建对象默认编辑**:新节点标题 / 新连线说明 / 新端口 label 自动进入编辑态,减少一步单击。
5. **双主题切换**:深色默认 + 浅色一键切换,导出保留当前主题。
6. **执行主体语义色**:人黄 / 机蓝 / 人机协同(紫文字 + 绿框),节点外框按主体着色;机器改纯正蓝避免偏青。
7. **选中不掩盖语义色**:节点 / 连线选中态提亮 + 光晕增强,不改边框语义色(避免"蓝=机器"与选中蓝混淆)。
8. **端口交互增强**:连接状态绿 / 桔光晕;命中区域放大;连接半径 28→40;悬停删除端口(每方向 ≥1)。
9. **连线层级(方案 C)**:默认节点在连线之上,拖拽时临时提升连线 / label。
10. **连线绕障**:连线不压节点(直角绕行 / 弧线拐弯),label / 产物随路径避开。
11. **组合节点精致化**:塌缩粗边框 / 展开虚线框;执行主体继承;展开塌缩动画。
12. **多项目多画布**:标签栏(项目标签 + 项目内画布标签,颜色点区分),不同项目不同色。
13. **操作提示框分平台**:mac 提示两指滑动 / 捏合,Windows 提示滚轮;快捷键符号区分(⌘ vs Ctrl)。

## 7. 画布导出规范

- 导出 JPG / PDF:**隐藏**操作提示框、全局缩略图、右下缩放控件,只导出画布内容。
- 保留主题背景色 + 点阵(深色导出深色,浅色导出浅色)。
- 默认横版,可选 A5 / A4 / A3 / Letter 幅面;完整画布**上下左右居中**,合理边距。
- SVG 暂置灰待完善(数据驱动矢量重绘)。
